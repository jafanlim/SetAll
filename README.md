## Features

- **Personal wallet** — income/expense tracking, 150+ currencies, live exchange rates
- **Group expenses** — split bills, track debts, settle with Greedy Flow algorithm
- **AI insights** — weekly analysis and monthly digest powered by Groq llama-3.3-70b
- **Home screen widget** — live balance, recent entries, quick-action buttons (iOS)
- **Monthly email digest** — spending summary, category chart, AI insight
- **Export** — PDF, CSV, JSON for personal and group data
- **Offline-first** — SQLite local storage with Supabase cloud sync

## Stack

Flutter · Supabase · SQLite · Riverpod · Firebase · Groq AI · Netlify · WidgetKit
